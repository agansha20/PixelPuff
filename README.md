# PixelPuff 🎁

PixelPuff is a customized gift website where users can explore and order personalized gifts for their loved ones.

## ✨ Features

- 🎁 Customized gift products
- 🛒 Easy product browsing
- 💝 Personalized gift options
- 📩 Contact and order form
- 📧 Email notification for customer orders
- ✅ Automatic order confirmation email
- 📱 Responsive design
- ⚡ Built with React + Vite

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS
- EmailJS

## 📧 Contact

Customers can use the Contact Us page to send their customized gift requirements.

When an order is submitted:

1. The order details are sent to the PixelPuff email.
2. The customer receives an automatic thank-you email.
3. The customer is informed about their order and delivery time.
